Paste the raw Cookie header value from a logged-in Ultimate Guitar browser session. It's one long line of key=value pairs.

How to get it:
1. Log into ultimate-guitar.com in Chrome/Safari/Firefox.
2. Open any tab page (e.g. your Deep Satin URL).
3. Press F12 (or long-press → Inspect on some Android browsers).
4. Go to the Network tab → refresh the page.
5. Click the first request in the list.
6. Scroll to Request Headers → find cookie:.
7. Copy the entire value and paste below.
